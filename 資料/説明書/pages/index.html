画面の見方

03

HEADS-UP DISPLAY

  • AP（中央下）：機体の耐久値。0 になると作戦失敗です。
  • 照準の円：ミサイルのロック範囲。周りの弧に武器のオーバーヒートゲージ・ミサイルの装填・ブーストのエネルギーが表示されます。
  • ALT / SPD（照準の左右）：地面からの高度と、今の速度（km/h）。
  • TIME / SCORE（右上）：経過時間と、敵を倒して得た得点。

05 / MISSION

作戦 01「DESERT」

05

OBJECTIVE

旧文明の遺構が砂に沈む、広大な砂漠の闘技場。3つのウェーブを勝ち抜き、敵勢力を殲滅してください。

  • WAVE 1・2：ミサイルや弾を撃ってくる無人機（ドローン）の群れ。
  • WAVE 3：地中から現れる巨大生物「ボイドワーム」。無数の個体が集まって体を作り、うねりながら襲ってきます。

クリアと失敗

ボイドワームを倒すと MISSION COMPLETE。AP が 0 になると MISSION FAILED。リザルトでは作戦時間とスコアを確認し、格納庫へ戻ります。

闘技場の外へは出られません。端に近づくと境界の壁が見えます。
BOSS / VOID WORMSCREEN CAPTURE 05

ボイドワームは砂を巻き上げて地中から現れます。距離を取りつつ、肩のミサイルで群れの体をまとめて削りましょう。

06 / SETTINGS

設定画面

06

CONFIGURATION

  • GAME：FPS の上限（30〜240 / VSync / 無制限）、FPS の表示
  • GRAPHICS：ウィンドウモード、明るさ、ブルーム、画面の揺れ、HUD の表示
  • SOUND：全体・BGM・効果音・UI の音量
  • INPUT：マウス感度（パッドではスティック感度）、視点の上下反転、キー割り当て

変更方法

左のタブで分類を選び、右の項目で値を変えます。数値はバーをドラッグするか左右で増減、ON/OFF は押して切り替え。キー割り当ては行を押してから新しいキーを押します。

変更はすぐに反映され、BACK（Esc / 右クリック / B）で閉じると保存されます。タイトル・格納庫のメニュー・一時停止から開けます。

LOADOUT

装備を変更する

機体の4つの取り付け口（右手・左手・右肩・左肩）に、今の武器が箱で表示されます。箱を選ぶとその武器へカメラが寄り、左に武器の一覧が出ます。一覧で押した武器にその場で付け替わり、次の出撃に反映されます。

選べる武器

  • 手：MACHINE GUN / LIGHT MECH GUN / ASSAULT RIFLE / HEAVY MACHINE GUN / BURST WEAPON / 各 X02 型（3種）
  • 肩：MISSILE POD

性能を確認する

一覧で武器にカーソルを乗せると性能の板が切り替わります。白い棒が今付けている武器です。

戻る（Esc / 右クリック / B）で、寄り → 全体 → 格納庫の順に戻ります。
GARAGE / LOADOUTSCREEN CAPTURE 07
